# Oak & Arc Interiors

A responsive one-page website for a fictional interior design studio, built to demonstrate frontend development and interaction design skills.

🔗 **Live Demo:** https://oak-and-arc-interiors.netlify.app

## ✨ Features

- **Responsive design**: optimized from 320px mobile up to 1440px+ desktop
- **Sticky navbar** with a mobile hamburger menu
- **Project filtering**: All / Residential / Commercial, powered by JavaScript
- **Scroll-reveal animations** using the IntersectionObserver API
- **Clean typography**: Playfair Display + Inter (Google Fonts)
- **Accessible**: semantic HTML and `prefers-reduced-motion` support

---

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 (custom properties, flexbox, grid) |
| Interactivity | Vanilla JavaScript (ES6+) |
| Fonts | Google Fonts |
| Icons | Font Awesome |
| Hosting | Netlify |

**No frameworks. No build step. Pure HTML, CSS, and JS.**

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Arishlinuxuser/oak-and-arc-interiors.git
   ```

2. Open the folder in your editor.

3. Open `index.html` in your browser. No build step needed.
